# Asymptotic Complexity Analysis (TensorFlow/Keras)

Generated by `resource_scaling.py` (Sections 3.9.2 and 3.10.2).

## 1. Theoretical Complexity

| Model | Time | Space | Rationale |
|---|---|---|---|
| lstm | O(N) | O(N) | The LSTM encoder processes the window one keystroke at a time through recurrent memory cells. Each of the N steps does a constant amount of work (gate computations sized by hidden_dim), so total time and activation memory scale linearly with the window length N. |
| transformer | O(N^2) | O(N^2) | Multi-Head Self-Attention computes an N x N attention score matrix -- every keystroke attends to every other keystroke in the window -- so both time and memory scale quadratically with N. The feed-forward sublayers alone would be O(N), but attention dominates for the window sizes used here. |
| lstformer | O(N) + O(N^2) = O(N^2) | O(N) + O(N^2) = O(N^2) | Track A (LSTM branch) contributes O(N); Track B (Transformer branch) contributes O(N^2). The two branches run in parallel and their costs add, so the quadratic term from the attention branch dominates asymptotically. In practice the constant factor is smaller than a deep stand-alone Transformer because the LST-Former's Transformer branch offloads local rhythm modeling to the cheaper LSTM branch. |
